# Romi_Im

세이마이네임(SAY MY NAME) 비공식 팬 아카이브 사이트. 팬튜브 채널 Romi_Im(@smn00000)의 라이브 압축본과 세마넴 공개 정보를 모아 둔다.

소속사와 관계없는 비공식 팬 사이트입니다. 문의·삭제 요청: rhfo4333@gmail.com

- 기획: [docs/기획서.md](docs/기획서.md)
- 데이터 고치는 법: [data/README.md](data/README.md)
- 사이트 주소: https://rhfo2253-eng.github.io/romi-im/

## 직접 돌려 보기

```bash
npm install
npm run dev      # http://localhost:4321/romi-im/
npm run build    # dist/ 에 사이트가 만들어짐
```

`main` 브랜치에 올리면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 올린다(`.github/workflows/deploy.yml`).
