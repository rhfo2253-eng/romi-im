# 데이터 파일 설명

사이트의 모든 내용은 이 폴더의 JSON 파일에서 나옵니다. 파일을 고치고 `main`에 올리면 사이트가 자동으로 다시 만들어집니다.

공통 규칙
- 날짜는 `YYYY-MM-DD` 형식(예: `2026-10-19`)으로 씁니다.
- 길이와 시간은 **초** 단위 숫자로 씁니다(예: 3분 25초 → `205`).
- 멤버는 아래 멤버 id로 적습니다: `hitomi` `shuie` `mei` `kanny` `soha` `dohee` `junhwi` `seungju`
- `"sample": true`가 붙은 항목은 화면 확인용 샘플입니다. 사이트에 "샘플" 표시가 붙습니다. 실제 데이터가 들어오면 샘플 파일·항목은 지웁니다.
- 세이마이네임 공개 정보(멤버, 디스코그래피, 기념일)에는 반드시 `source`(출처 URL)를 답니다. 출처가 없으면 넣지 않습니다.
- 가사, 사생활, 루머, 공식 사진·영상 파일은 넣지 않습니다.

## `episodes/<YYMMDD_이름>.json` — 압축본 한 편

파일 하나가 압축본 한 편입니다. 파일 이름에서 `.json`을 뺀 부분이 `id`이고 주소가 됩니다(`/episodes/<id>/`).

| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 파일 이름과 같게 | `"261019_2주년라이브"` |
| `no` | 몇 편인지(선택) | `2` |
| `liveTitle` | 위버스 라이브 원래 제목(선택) | `"세마넴 데뷔 2주년"` |
| `title` | 압축본 제목 | `"데뷔 2주년 축하 라이브 압축본"` |
| `liveDate` | 원본 라이브 날짜 | `"2026-10-19"` |
| `publishDate` | 압축본 유튜브 공개일. **비어 있거나(`null`) 오늘보다 뒤면 비공개로 보고 사이트에 안 보임.** 사이트는 매일 0시 7분(한국 시간)에 다시 만들어져서 공개일이 되면 자동으로 나타남 | `"2026-10-21"` |
| `youtubeId` | 유튜브 영상 id(`watch?v=` 뒤 11자) | `"dQw4w9WgXcQ"` |
| `duration` | 영상 길이(초), 모르면 `null` | `1840` |
| `members` | 나온 멤버 id 목록 | `["hitomi", "mei"]` |
| `anniversary` | 기념일 편이면 이름, 아니면 `null` | `"데뷔 2주년"` |
| `chapters` | 장면 목록. `title`(장면 이름), `time`(시작 초, 모르면 `null` → 누르면 처음부터 재생) | `[{"title": "인사", "time": 0}]` |
| `shorts` | 이 라이브에서 나온 쇼츠. `youtubeId`, `title` | `[{"youtubeId": "...", "title": "..."}]` |
| `weverseUrl` | 원본 위버스 라이브 주소, 없으면 `null` | |
| `thumbnail` | 따로 쓸 썸네일 주소. `null`이면 유튜브 썸네일(채널이 만든 것)을 씀 | `null` |
| `sample` | 샘플이면 `true`(실제 편에는 빼기) | |

세마넴라이브압축 작업의 `edl.py`와 연결하면: `TITLE` → `title`, `CHAPTERS` → `chapters`(시간을 초로 바꿔서), `SHORTS` → `shorts`, 업로드 결과 → `youtubeId`.

## `lives.json` — 전체 위버스 라이브 기록

압축하지 않은 라이브까지 모두 적는 목록입니다.

| 칸 | 뜻 |
|---|---|
| `id` | 겹치지 않는 이름(예: `"261019-anniversary"`) |
| `date` | 라이브 날짜 |
| `title` | 라이브 제목 |
| `members` | 나온 멤버 id 목록 |
| `duration` | 길이(초), 모르면 `null` |
| `weverseUrl` | 위버스 주소, 없으면 `null` |
| `episodes` | 이 라이브로 만든 압축본 `id` 목록(아직 비공개인 편은 사이트에 자동으로 안 보임). 한 라이브를 여러 편으로 나눴으면 여러 개, 없으면 `[]` |
| `sample` | 샘플이면 `true` |

## `members.json` — 멤버

| 칸 | 뜻 |
|---|---|
| `id` | 멤버 id(위 목록, 바꾸지 않기) |
| `name` | 화면에 보이는 이름 |
| `color` | 멤버 색(점, 밑줄, 필터 칩에만 씀) |
| `colorDark` | 어두운 모드에서 대신 쓸 색(선택). 준휘처럼 검정이면 밝은 회색으로 |
| `colorName` | 색 이름(예: `"노랑"`) |
| `colorSource` | 멤버 색 출처 URL |
| `facts` | 공개 정보 목록. 항목마다 `label`, `value`, `source`(출처 URL) |

생일을 확인하면 `facts`에 `{"label": "생일", "value": "10월 6일", "source": "..."}`처럼 넣고, 달력에도 보이게 `events.json`에 `type: "birthday"`로 추가합니다.

## `discography.json` — 앨범·곡

| 칸 | 뜻 |
|---|---|
| `id` | 겹치지 않는 이름 |
| `title` | 앨범·싱글 제목 |
| `type` | `"미니 1집"`, `"싱글"` 등 |
| `releaseDate` | 발매일. 발표만 되고 날짜가 안 정해졌으면 `null` |
| `status` | 날짜가 없을 때 대신 보일 말(예: `"발매 예정 · 일자 미정"`) |
| `titleTrack` | 타이틀곡 제목 |
| `mv` | 공식 뮤직비디오 유튜브 주소, 모르면 `null` |
| `source` | 출처 URL |

## `events.json` — 달력에 넣을 날

발매일과 압축본 공개일은 위 파일에서 자동으로 달력에 들어가므로, 여기에는 생일·기념일·방송 출연·공연처럼 따로 적어야 하는 날만 넣습니다.

| 칸 | 뜻 |
|---|---|
| `id` | 겹치지 않는 이름 |
| `date` | 날짜. 매년 반복하는 날은 처음 날짜(예: 데뷔일 `2024-10-16`) |
| `repeat` | 매년 반복이면 `"yearly"`, 아니면 빼기 |
| `type` | `"birthday"`(생일), `"anniversary"`(기념일), `"broadcast"`(방송·유튜브 출연), `"event"`(공연·행사·시구 등) |
| `title` | 달력에 보일 이름 |
| `source` | 출처 URL |

## `photos.json` — 사진(공식 게시물)

공식 X·인스타그램 게시물 주소만 적습니다. 사진 파일은 저장하지 않고, 사이트에서는 원래 게시물을 그대로 띄웁니다(게시물이 지워지면 사이트에서도 안 보임). 위버스는 퍼가기가 안 돼서 링크로만 보입니다.

| 칸 | 뜻 | 예 |
|---|---|---|
| `url` | 게시물 주소 | `"https://x.com/sa2m2nam3/status/2094001721467183140"` |
| `platform` | `"x"`, `"instagram"`, `"weverse"` 중 하나 | `"x"` |
| `date` | 게시일 | `"2026-08-30"` |
| `members` | 나온 멤버 id 목록 | `["mei"]` |
| `note` | 게시물을 못 불러올 때 대신 보일 짧은 설명(선택) | `"#SAY_MEI"` |
