## 지킬 선(사회 통념 안에서)
- 맨 아래와 소개 페이지에 **"비공식 팬 사이트이며 소속사와 관계없음"**을 적는다. 공식 로고는 쓰지 않는다.
- 멤버 정보는 **공식 채널과 공식 프로필에 공개된 것만** 넣는다. 사생활, 루머, 출처 없는 정보는 넣지 않는다.
- 공식 사진과 영상을 다시 올리지 않는다. 영상은 유튜브 퍼가기와 링크만, 이미지는 채널이 직접 만든 썸네일만 쓴다.
- 노래 가사는 싣지 않는다. 곡은 제목과 공식 링크만 넣는다.
- 다른 팬이나 그룹을 깎아내리는 글, 순위 비교는 넣지 않는다. 광고도 붙이지 않는다.
- 삭제 요청이 오면 바로 내릴 수 있게 연락 방법을 둔다.

## 디자인 방향
- 밝은 모드와 어두운 모드 둘 다(기본은 기기 설정을 따름). 채널 썸네일과 이어지는 노란색 강조.
- 글꼴은 Pretendard(채널 자막과 같음). 큰 제목, 넉넉한 여백.
- 요즘 많이 쓰는 방식: 크기가 다른 카드를 섞은 그리드(벤토), 은은한 반투명 메뉴 막대, 페이지가 부드럽게 넘어가는 효과, 카드에 마우스를 올리면 살짝 떠오르는 효과.
- 멤버 색은 포인트로만 쓴다(점, 밑줄, 필터 칩).
- 폰에서 먼저 보기 좋게 만든다(팬 대부분이 폰으로 봄).

## 기술 방향(제안)
- **Astro** 정적 사이트 + 데이터 파일(JSON). 빌드하면 HTML만 나와서 빠르고 무료로 올릴 수 있다.
- GitHub 저장소 `rhfo2253-eng/romi-im` → GitHub Actions가 자동으로 빌드해서 Pages에 올린다. 주소는 `rhfo2253-eng.github.io/romi-im`.
  - 무료 GitHub Pages는 **저장소가 공개**여야 한다. 저장소에는 사이트 코드와 공개해도 되는 데이터만 넣는다.
- 데이터 구조
  - `data/episodes/<YYMMDD_이름>.json`: 제목, 라이브 날짜, 공개일, 유튜브 id, 길이, 멤버, 챕터(이름, 시간), 쇼츠 id, 위버스 링크, 썸네일
  - `data/members.json`, `data/lives.json`, `data/discography.json`, `data/events.json`
- 자동 추가: 세마넴라이브압축 스킬 마지막에 `edl.py`(TITLE, CHAPTERS, SHORTS)와 업로드 결과(유튜브 id)로 에피소드 JSON을 만들어 `romi-im` 저장소에 커밋하는 단계를 넣는다.
